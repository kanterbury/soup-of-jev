# UI デザインのモックアップ

プレイ画面などの見た目の決定版。仕様（配色・書体・判定の表示方法・Tailwind のトークン案）は `docs/app-design.md` の §6.4 にまとめてあり、このフォルダはその元になった画面そのもの。

- **キャンバス（原本）**：https://claude.ai/artifact/6gNpSDYEA2DSWMcPEoF7Ln（非公開。Claude Code からは Artifact ツールの `read` で各画面のソースを読める）
- **このフォルダ**：2026-09-22 時点（キャンバスの Version 11）の各画面のソースを保存したもの。キャンバスを更新したら、ここも更新する。

## ファイル

| ファイル                    | 画面                                           | 実装での対応                                           |
| --------------------------- | ---------------------------------------------- | ------------------------------------------------------ |
| `mockups/Main.dc.html`      | スタイル見本（配色・書体・判定の表示・ボタン） | デザイントークン（`src/app/globals.css` の `@theme`）  |
| `mockups/List.dc.html`      | 問題一覧（PC, 1280×900）                       | `/`（`src/app/page.tsx`）                              |
| `mockups/Play.dc.html`      | プレイ画面（PC, 1440×960）                     | `/puzzles/[id]`（`src/app/puzzles/[id]/PlayView.tsx`） |
| `mockups/PlayPhone.dc.html` | プレイ画面（スマホ, 390×844）                  | 同上のスマホ幅での表示                                 |
| `mockups/Reveal.dc.html`    | 真相の表示（正解したとき）                     | プレイ画面の中の、正解後・「真相を見る」後の表示       |

## 読み方の注意

- 各ファイルは、デザイン用キャンバスの形式（`.dc.html`）で書かれている。先頭の `<script src="./support.js">` はキャンバス側の実行環境なので、ブラウザで直接開いても正しく表示されない。見た目を確かめるときはキャンバスを開く。
- スタイルはすべて要素に直接書いてある（インラインの `style`）。実装では、色や書体を `@theme` のトークンに置き換え、Tailwind のクラスで書く。値は `docs/app-design.md` §6.4 の表を正とする。
- 画面の中の質問・判定・回答の結果（「3 つの要点のうち 1 つ」など）は、見た目を示すための例で、実際の判定結果ではない。
- 画面の大きさは固定だが、実装はレスポンシブにする。背景は画面（ビューポート）に固定し、内容だけをスクロールさせる。
